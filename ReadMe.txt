Tone Matrix 1.0.2
Generate a random serial music twelve-tone matrix
Fonazza-Stent 2025

The purpose of the program is to generate a twelve-tone matrix, to
inspire Arnold Schönberg style serial music compositions. Just
run the program and a matrix will be displayed with Basic Set,
Inverted Set, Retrograde Set, Retrograde Inverted Set, complete
with all transpositions.

- Click on “New Matrix” to generate a new matrix
- Click on “Save” to save a screenshot of the matrix
- Click on “Exit” to quit the program

You can also enter your own Basic Set in the box below the buttons.
Enter notes in capital letters (i.e. D C# B F#) and press OK or Enter
on the keyboard. The program will parse the content of the box and
find all the notes, regardless of the fact they are separated or not by
a space and discarding automatically all characters not corresponding
to notes. If you input a partial series, the program will complete
it with the rest of the notes.
