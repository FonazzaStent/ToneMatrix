Tone Matrix 1.0.0
Generate a random serial music twelve-tone matrix
Fonazza-Stent 2025

The purpose of the program is to generate a twelve-tone matrix, to
Inspire Arnold Schoenberg style serial music compositions. Just
run the program and a matrix will be displayed with Basic Set,
Inverted Set, Retrograde Set, Retrograde Inverted Set, complete
with all twelve transpositions.
